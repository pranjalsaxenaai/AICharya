# AICharya

Repository containing collectable reference/research data.

## Contents

### `PDFs/`
SSC CGL Previous Year Question Papers — 398 PDFs (582 MB) downloaded from
Adda247 (https://www.adda247.com/jobs/ssc-cgl-previous-year-question-paper/).

Structure (mirrors the site upload layout):
- `PDFs/jobs/wp-content/uploads/<year>/<batch>/` — official question papers
- `PDFs/wp-content/uploads/multisite/...` — CGL 2019 Tier-2 subject papers

See `.opencode/context/` for a full dataset breakdown (exams, years, subjects, languages).
